# gonk-core 0.13.3

All 20 `@gonk/*` packages in gonk-core move to 0.13.3. No code changed since
0.13.2. This release exists because a published README cannot change, and the
nine public packages needed their diagrams before the public npm release.

- The READMEs of `@gonk/tool-registry` and `@gonk/tool-registry-mcp` show
  `assets/architecture.svg`. The README of `@gonk/scope` shows
  `assets/scope-resolution.svg`.
- The images load from `raw.githubusercontent.com` on `main`, because npm does
  not serve repository files.
- `architecture.svg` now matches the packages: Codex and MCP over stdio or
  HTTP are hosts, `@gonk/extension-spec-codex` and `@gonk/utils` appear, and
  no label is smaller than 11px. Both diagrams have a dark colour scheme.

Everything in `0.13.2.md` still applies.
